# Karam Alawaj — a living portfolio

**[Open the interactive 3D portfolio →](https://karamalawaj.github.io/)**

Explore five selected engineering projects, a professional profile and a guided journey with NEXUS AI. An original architectural Blender studio, five project dioramas and a skinned NEO presenter with 24 authored motions. Includes bilingual recorded narration, semantic exhibit effects, adaptive mobile assets, original ambient music and a conversational AI companion.

This repository hosts the compiled files required by GitHub Pages. Editable artwork, authoring files and backend implementation remain private. Browser JavaScript and 3D assets must be delivered to visitors to run the experience; they cannot be made impossible to inspect or extract.

Project information is drawn from [Karam's public profile](https://github.com/Karamalawaj) and public showcases. Full project implementations and sensitive data are not published here. Healthcare projects are portfolio prototypes, not production medical systems. Presentation audio uses pre-generated Gemini clips; dynamic chat can use device/browser speech without Gemini TTS, or an optional online NEO voice from the private Nexus AI service. Device voice language availability depends on the browser and operating system. Music is original synthesized audio. See the site's privacy notice.
